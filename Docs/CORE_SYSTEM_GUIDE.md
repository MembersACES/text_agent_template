## Purpose

This guide defines the standard structure, formatting, and quality expectations for **Base 1 Review** Excel workbooks and related analysis outputs generated by the ACES app (`ExcelGeneratorService` / `SheetsGeneratorService`).

---

## Standard Excel workbook structure

The template targets **eight named sheets**. **Order in the generated XLSX:**

1. **Overview** — Executive summary, client info, savings band (when provided)  
2. **Electricity Data** — *(only if there is at least one electricity invoice; otherwise empty placeholder)*  
3. **Gas Data** — Same pattern  
4. **Waste Data** — Same pattern  
5. **Water Data** — Same pattern  
6. **Oil Data** — Same pattern  
7. **Cost Summary** — Counts and totals by utility type  
8. **Meter Details** — Utility, meter, NMI/MRIN, site, tariff  
9. **Base 1 Analysis** — Benchmarking summary, roll-up, totals  

**Implementation detail:** Sheets **2–6** appear **twice in generation order** — tabs **with** data first, then **empty** tabs for utilities with no invoices — so workbook order is **Overview → populated utility tabs → empty utility tabs → Cost Summary → Meter Details → Base 1 Analysis**. Names still match the eight utility/data concepts plus the three summary sheets.

**Cleaning:** Invoices with `utility_type: "Cleaning"` appear in **Cost Summary** and **Meter Details** sort order but **do not** have a dedicated **“Cleaning Data”** sheet in the current generator — only the five utility data tabs above.

## Formatting standards

- **Headers:** Blue background **#366092**, white text, bold (**~12 pt in Base 1 banners**; Excel uses white on blue for data headers)  
- **Totals rows:** Yellow highlight **#FFD966**, bold  
- **Currency:** `$X,XXX.XX` (AUD)  
- **Dates:** `DD/MM/YYYY` in extraction JSON  
- **Numbers:** Prefer comma thousands in presentational exports where formatted

## Sheet: Overview

Typical blocks:

1. Title  
2. Business / address / report generated / invoice count  
3. Optional **savings summary** rows (conservative / moderate / optimistic + “our costs” month-one)  

---

## Sheet: Base 1 Analysis (critical)

**What the app emits today (aligned with code):**

1. **Estimated annual savings** one-liner (merged **A–E**) when `savingsSummary` is present  
2. **Benchmarking Summary** — banner row + table  
   - Columns: **Category** | **Option Type** | **Amount Of Invoices** | **Total Savings Per Year (Estimated)** | **Related Charges**  
3. **Roll-up Summary** — banner + dual header (**Summary** | **Estimated Savings Per Year**) + rows (truncated list if many groups)  
4. **Total Savings (Estimation)** — conservative / moderate / optimistic and month-one fee columns  

**Removed / not in current generator (older KB text):**

- ❌ **Critical Issues** block (🔴 CRITICAL) — not written by `ExcelGeneratorService` / `SheetsGeneratorService` in the current layout  
- ❌ **Immediate Actions / Short-term Actions / Next Steps for Base 2** — not automated in these services  

If those sections are still required for **human-authored** workbooks, treat them as **manual add-ons** outside the default export pipeline.

## Quality assurance checklist

**Structure**

- [ ] Expected sheet **names** exist (Overview, five utility data sheets, Cost Summary, Meter Details, Base 1 Analysis)  
- [ ] No surprise renames that break client macros  

**Data quality**

- [ ] Numeric fields are numbers in JSON, not strings  
- [ ] No unevaluated formula text in cells (“100+200”)  
- [ ] Currency formatting applied on money columns where implemented  
- [ ] Dates in **`DD/MM/YYYY`** in extraction  

**Analysis**

- [ ] Base 1 Analysis present  
- [ ] Severity / savings come from **deterministic rules** (electricity/gas) or **extracted** `low_hanging_fruit` (water/waste/oil/cleaning)  
- [ ] Conservative (**70%**), moderate (**85%**), optimistic (**100%**) roll-up of calculated savings when summary is built upstream
